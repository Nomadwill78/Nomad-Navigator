# Changelog

## 2.0.0-alpha.1

First preview of Nomad Compass v2, built as an app on Twenty CRM.

- Grants, KPIs, subgrantees and monthly program results, carried over from v1 with the same KPI rules, plus grant pace, a data check and report reminders.
- Donors, gifts, campaigns, volunteers and hours, with calculated giving status and totals.
- Cultivation plans on a board, with next steps and a forecast.
- Reminders: thank-yous, donors at risk, reports due, background checks.
- AI donor insight and funder report draft with fact checking and privacy limits.
- Saved views, sidebar, home dashboard, four team roles, sample data, a donation route for Zapier, a v1 importer, and spreadsheet templates.
- Not yet run against a live Twenty server. See `docs/KNOWN_LIMITS_AND_NEXT_STEPS.md`.
